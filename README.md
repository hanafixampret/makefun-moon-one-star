A one-star review of the Moon, 120 characters at most, for the
[make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5).

`main.ts` writes the entry to `/output/entry.txt`:

> ★☆☆☆☆ Drags the ocean around without asking, vanishes for a week, then shows up full of itself. Rude. One star.

Run it with Node 22+:

```sh
node main.ts
```
